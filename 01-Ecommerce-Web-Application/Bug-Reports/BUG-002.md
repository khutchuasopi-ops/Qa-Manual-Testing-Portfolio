# BUG-002 — Cart total price does not change when product quantity is updated

## Bug Information

| Field | Details |
|---|---|
| Bug ID | BUG-002 |
| Severity | High |
| Priority | High |
| Status | Reported |
| Application | E-commerce Web Application |
| Platform | Web |

## Preconditions

A product has been added to the shopping cart.

## Steps to Reproduce

1. Add a product to the shopping cart.
2. Open the shopping cart.
3. Change the product quantity.
4. Observe the cart total price.

## Expected Result

The cart total price should be recalculated and updated according to the selected product quantity.

## Actual Result

The cart total price does not change after the product quantity is updated.

## Notes

The issue affects the accuracy of the shopping cart total.
