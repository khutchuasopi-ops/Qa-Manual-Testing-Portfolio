# E-commerce Web Application — Manual QA Testing

## Project Overview

This project demonstrates practical **Manual QA Testing** activities performed on a confidential e-commerce web application.

The project focuses on testing the main customer journeys and documenting the complete QA workflow from test design through defect reporting and test summary.

> **Confidentiality Note:** The application name, organization name, URL, credentials, and confidential business or user information are intentionally excluded from this portfolio.

---

## Testing Scope

The following areas were covered:

* User Login and Authentication
* Product Search
* Product Details
* Size Selection
* Shopping Cart
* Product Quantity Management
* Checkout Flow
* Delivery and Payment

* Navigation and UI

## Documented Defects

Three defects were documented during manual testing:

* **BUG-001** — Localization content remained in English after changing the selected language.
* **BUG-002** — Shopping cart total did not update correctly after changing product quantity.
* **BUG-003** — Invalid email credentials were accepted during login.

Detailed reproduction steps and expected/actual results are available in the [Bug Reports](Bug-Reports/) folder.
