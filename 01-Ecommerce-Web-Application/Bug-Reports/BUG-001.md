# BUG-001 — Website Content Remains in English After Changing Language

**Severity:** Medium
**Priority:** Medium
**Status:** Reported
**Environment:** Web Application
**Module:** Localization

## Description

After changing the website language, the content remains displayed in English instead of the selected language.

## Steps to Reproduce

1. Open the e-commerce web application.
2. Select a language other than English.
3. Check the website content.

## Expected Result

The website content should be displayed in the selected language.

## Actual Result

The website content remains in English after changing the language.
