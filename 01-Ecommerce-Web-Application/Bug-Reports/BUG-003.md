# BUG-003 — Invalid Email Accepted During Login

## Bug ID

BUG-003

## Summary

Invalid email credentials are accepted during the login process.

## Environment

* Application: Confidential E-commerce Web Application
* Browser: Google Chrome
* Testing Type: Manual Functional Testing
* Environment: Web Application

## Preconditions

* A test account exists.
* User is on the Login page.
* A valid password is available for the test account.

## Test Data

* Email: Invalid / non-existent email address
* Password: Valid test account password

> No real user credentials or personal information are included.

## Steps to Reproduce

1. Open the Login page.
2. Enter an invalid or non-existent email address.
3. Enter a valid test account password.
4. Click the Login button.
5. Observe the result.

## Expected Result

The system should reject invalid email credentials and display an appropriate error message. The user should not be authenticated or redirected to the home page.

## Actual Result

The system accepted the invalid email credentials and redirected the user to the home page.
