# BUG-002 — Unable to Return from Operator Mode

**Environment:** Web application, manual testing

**Severity:** High
**Priority:** High
**Status:** Open

### Steps to Reproduce

1. Open the chatbot.
2. Start a conversation.
3. Request to connect to an operator.
4. After entering operator mode, request to return to the AI chatbot.

### Actual Result

The chatbot remains in operator mode and does not return to the AI conversation.

### Expected Result

The user should be able to return to the AI chatbot, if this action is supported by the application.
