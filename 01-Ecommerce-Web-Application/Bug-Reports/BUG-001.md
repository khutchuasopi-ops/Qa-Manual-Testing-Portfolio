# BUG-001 — Website Content Remains in English After Changing Language

| Field                 | Details                                                    |

| Status                | Reported                                                   |
| Test Type             | Functional / Localization                                  |
| Related Test Case     | TC-036                                                     |

## Description

After selecting a different language, the website content remains in English instead of being displayed in the selected language.

## Preconditions

* The e-commerce web application is accessible.
* The language selection option is available.

## Steps to Reproduce

1. Open the e-commerce web application.
2. Locate the language selection option.
3. Select a language other than English.
4. Review the visible website content.

## Expected Result

The website content should be displayed in the selected language.

## Actual Result

The website content remains in English after changing the language.

## Impact

The issue may cause confusion for users who expect the interface and content to be displayed in their selected language.

## Evidence

Evidence can be attached when available, such as:

* Screenshot showing the selected language.
* Screenshot showing the content remaining in English.

## Regression Testing

After a fix, verify:

* Language selection changes the displayed content.
* Navigation labels are translated correctly.
* Buttons and UI labels use the selected language.
* Validation and error messages use the selected language.
* Product information is displayed consistently.
* The page does not contain mixed-language content.

## QA Note

This defect was identified during manual testing of the localization functionality. No technical root cause is assumed because the issue was evaluated from the user-facing behavior.
