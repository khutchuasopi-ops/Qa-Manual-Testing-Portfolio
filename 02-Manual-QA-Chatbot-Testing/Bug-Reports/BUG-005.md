# BUG-005 — Chatbot does not properly handle multiple product requirements

## Title

Chatbot focuses on one attribute instead of handling the full user request

## Environment

- Platform: Alta AI Chatbot
- Browser: Web browser
- Testing type: Manual / Exploratory Testing

## Preconditions

- Chatbot is available.
- User is looking for a laptop.

## Steps to Reproduce

1. Open the chatbot.
2. Send the following request:

   `color RAM price design material battery warranty gaming office`

3. Review the chatbot response.
4. Check whether the response addresses the different requirements.
5. Continue the conversation if the chatbot asks a follow-up question.

## Actual Result

The chatbot provides general information about Asus Vivobook Go models and
then asks:

`Which RAM capacity would be your priority?`

The response focuses mainly on RAM and does not properly address the other
requirements provided by the user, such as:

- color
- price
- design
- material
- battery
- warranty
- gaming performance
- office use

The chatbot does not clearly organize the requirements or explain which ones
can be satisfied by the suggested products.

## Expected Result

The chatbot should recognize the different requirements in the user's message.

It should either:

1. provide a structured response covering the main requested attributes, or
2. ask relevant clarification questions when the requirements are too broad or
   conflict with each other.

The response should not reduce a complex request to only one attribute without
explaining why.

## Severity

Medium

## Priority

Medium

## Impact

The user may not receive a recommendation that matches their actual needs.

Important requirements can be missed, which can make the product
recommendation less useful and may lead the user to choose an unsuitable
product.

## Evidence

User input included multiple requirements:

`color RAM price design material battery warranty gaming office`

The chatbot responded with information about RAM and then asked which RAM
capacity the user preferred, without properly addressing the other requested
attributes.
