# BUG-003 — Operator State Persists After Minimize/Reopen

**Environment:** Web application, manual testing

**Severity:** Medium
**Priority:** High
**Status:** Open

### Steps to Reproduce

1. Open the chatbot.
2. Start a conversation.
3. Request to connect to an operator.
4. Minimize the chatbot.
5. Reopen the chatbot.
6. Observe the conversation state.

### Actual Result

After reopening the chatbot, the previous operator state is still displayed.

### Expected Result

The chatbot should display the correct conversation state after being minimized and reopened, according to the expected application behavior.
