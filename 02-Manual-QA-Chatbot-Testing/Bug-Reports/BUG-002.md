# BUG-002 — Chatbot remains in operator state after user tries to return to AI

## Title

Chatbot does not allow the user to return to the AI chatbot after requesting an operator

## Environment

- Platform: Alta AI Chatbot
- Browser: Web browser
- Testing type: Manual / Exploratory Testing

## Preconditions

- Chatbot is open and working.
- User is having a normal conversation with the chatbot.

## Steps to Reproduce

1. Open the chatbot.
2. Start a conversation with the chatbot.
3. Send the message:
   `Connect me to operator`
4. Wait for the operator request confirmation.
5. Send:
   `Never mind. Can you return to chatbot?`
6. Check the chatbot response.
7. Minimize the chat using the available minimize button.
8. Open the chatbot again.
9. Try to continue the conversation with the AI chatbot.

## Actual Result

After the operator request is submitted, the chatbot remains in the operator
state.

When the user tries to return to the AI chatbot, the system responds that an
operator has already been requested.

After minimizing and reopening the chat, the previous operator state is still
shown.

The user does not have a clear option to start a new AI conversation or return
to the chatbot without refreshing the page.

## Expected Result

The chatbot should provide a clear way for the user to return to the AI
chatbot if returning to AI is supported.

If returning to AI is not supported after requesting an operator, the system
should clearly explain the state and provide an appropriate option, such as
starting a new conversation.

Minimizing and reopening the chat should not leave the user in a confusing
state without a clear next action.

## Severity

Medium

## Priority

High

## Impact

The user can become stuck in the operator flow even when they no longer want
operator assistance.

This makes the conversation flow confusing and may prevent the user from
continuing to use the chatbot normally.

## Evidence

The chatbot confirmed that an operator had been requested.

When the user later asked to return to the chatbot, the system continued to
respond that an operator had already been requested.

The same state remained after minimizing and reopening the chat.
