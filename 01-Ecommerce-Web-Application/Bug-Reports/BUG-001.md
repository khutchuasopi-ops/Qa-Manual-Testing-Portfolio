# BUG-001 — Website content remains in English after changing language

## Bug Information

| Field | Details |
|---|---|
| Bug ID | BUG-001 |
| Severity | Medium |
| Priority | Medium |
| Status | Reported |
| Application | E-commerce Web Application |
| Platform | Web |

## Preconditions

User is on the website and the language selection option is available.

## Steps to Reproduce

1. Open the e-commerce website.
2. Open the language selection option.
3. Select a language other than English.
4. Observe the website content.

## Expected Result

The website content should be displayed in the selected language.

## Actual Result

The website content remains in English after another language is selected.

## Notes

The issue affects the localization functionality of the website.
