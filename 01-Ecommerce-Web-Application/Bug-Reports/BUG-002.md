# BUG-002 — Cart Total Price Does Not Update After Quantity Change

## Bug Information

| Field                 | Details                                                           |
| --------------------- | ----------------------------------------------------------------- |
| Bug ID                | BUG-002                                                           |
| Title                 | Cart total price does not change when product quantity is updated |
| Module                | Shopping Cart                                                     |
| Severity              | High                                                              |
| Priority              | High                                                              |
| Status                | Reported                                                          |
| Test Type             | Functional / Calculation                                          |
| Related Test Case     | TC-024                                                            |
| Related Test Scenario | TS-016                                                            |

## Description

When the quantity of a product in the shopping cart is changed, the cart total price does not update accordingly.

## Preconditions

* The e-commerce web application is accessible.
* A product can be added to the shopping cart.
* The shopping cart contains at least one product.

## Steps to Reproduce

1. Open the e-commerce web application.
2. Add a product to the shopping cart.
3. Open the shopping cart.
4. Note the current product quantity and total price.
5. Increase or otherwise change the product quantity.
6. Check the cart total price.

## Expected Result

The cart total should be recalculated based on the updated product quantity.

## Actual Result

The cart total price does not update after the product quantity is changed.

## Impact

The issue can result in an incorrect order total being displayed to the user and may affect confidence in the checkout process.

## Evidence

Evidence can be attached when available, such as:

* Screenshot before changing quantity.
* Screenshot after changing quantity.
* Recorded values showing the quantity and total price.

## Regression Testing

After a fix, verify:

* Increasing product quantity updates the total.
* Decreasing product quantity updates the total.
* Multiple products are calculated correctly.
* Removing a product recalculates the total.
* The checkout total matches the cart total.

## QA Note

This defect was identified during manual testing of the shopping cart. The report focuses on the observed user-facing behavior and does not assume a technical root cause.
