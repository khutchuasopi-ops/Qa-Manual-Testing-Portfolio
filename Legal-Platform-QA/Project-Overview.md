# Production Management Platform — QA

## Project Overview

This project covers manual QA testing of an anonymized production management platform used to manage production-related activities and information.

The testing focused on verifying core functionality, user workflows, data validation, business logic, and UI behavior.

## Testing Scope

The following areas were tested:

- Project Management
- Director Availability
- Production Budget
- Invoice Management
- Sales Activities
- File Management
- Cloud Integrations
- UI and Usability

## Testing Approach

The project was tested manually using the following testing techniques:

- Functional Testing
- Exploratory Testing
- Regression Testing
- Retesting
- Negative Testing
- Boundary Testing
- Data Validation
- Business Logic Validation
- UI and Usability Testing

The testing included both expected user flows and invalid or unexpected input scenarios.

## Test Documentation

The project contains manual QA documentation covering:

- Project Overview
- Test Scenarios
- Test Cases
- Checklists
- Test Execution
- Bug Reports
- Case Study

## Documented Defects

Six confirmed defects were documented during testing:

| Bug ID | Area | Issue |
|---|---|---|
| BUG-001 | Director Availability | Event cannot be added |
| BUG-002 | Project Management | Project Details fail to load |
| BUG-003 | Production Budget | Expense is not included in the total |
| BUG-004 | Invoice Management | Negative amount displays `[object Object]` |
| BUG-005 | Sales Activity | Meeting view displays Call activities |
| BUG-006 | UI/Usability | Button text becomes unreadable on hover |

## Key Findings

The testing identified issues affecting:

- Project information and details
- Director availability management
- Production budget calculations
- Invoice input validation and error handling
- Sales activity display
- UI readability and usability

The documented defects were reproduced manually and recorded with clear reproduction steps, actual results, expected results, severity, and environment information.
