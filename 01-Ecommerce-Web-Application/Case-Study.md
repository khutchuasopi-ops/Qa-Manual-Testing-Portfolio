# E-commerce Web Application — QA Case Study

## 1. Project Background

This project involved manual testing of an e-commerce web application.

The main objective was to verify that key user journeys and e-commerce functionality worked as expected and to identify defects that could affect the user experience.

## 2. Testing Objectives

The main testing objectives were:

- Verify core e-commerce functionality.
- Validate important user journeys.
- Check product search and selection.
- Verify product size selection.
- Verify shopping cart functionality.
- Check product quantity and price calculations.
- Verify language selection functionality.
- Identify and document defects.

## 3. Testing Approach

I approached the testing by first identifying the main functional areas of the application.

I created high-level test scenarios and then developed detailed test cases for important functionality.

I also created checklists to provide broader coverage of the main features.

During testing, I executed functional checks and documented defects when the actual behavior differed from the expected behavior.

## 4. Main Areas Tested

### Login

I checked the login functionality, including valid and invalid login scenarios and validation of required fields.

### Product Search

I checked product search functionality using different search conditions, including valid, invalid, and empty search queries.

### Product and Size Selection

I verified that users could select products and available sizes and that the selected size was retained when adding a product to the shopping cart.

### Shopping Cart

I tested adding products to the cart, changing product quantities, removing products, and verifying product and price information.

### Checkout

I reviewed the main checkout flow, including order information, delivery information, payment options, and order confirmation.

### Localization

I tested the language selection functionality and identified an issue where website content remained in English after another language was selected.

## 5. Defects Identified

During testing, I identified defects affecting the user experience and shopping functionality.

Examples include:

- Website content remained in English after changing the selected language.
- The cart total price did not change when the product quantity was updated.

The defects were documented with reproduction steps, expected results, actual results, severity, and priority.

## 6. Challenges

One of the challenges was ensuring sufficient coverage across different e-commerce user flows.

To address this, I divided the application into functional areas and created test scenarios, detailed test cases, and checklists for each area.

## 7. Outcome

The testing activities helped identify functional and usability issues in important parts of the e-commerce application.

The project also helped strengthen my practical understanding of manual testing, test documentation, defect reporting, and risk-based testing.

## 8. Key Learnings

Through this project, I gained practical experience in:

- Writing manual test cases.
- Creating test scenarios.
- Creating functional checklists.
- Identifying and documenting defects.
- Writing clear reproduction steps.
- Comparing expected and actual results.
- Testing e-commerce user journeys.
- Thinking from the end-user perspective.
