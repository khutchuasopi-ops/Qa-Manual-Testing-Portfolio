# BUG-001 — Product Price Mismatch

## Summary

The product price displayed by the chatbot does not match the current price shown on the linked product page.

## Environment

* Application: Confidential AI-Powered E-commerce Chatbot
* Platform: Web
* Browser: Web browser
* Testing Type: Manual / Exploratory Testing

## Preconditions

* Chatbot is available.
* User is searching for a laptop.
* Product information can be requested from the chatbot.
* A product page can be opened from the chatbot response.

## Test Data

* Product category: Laptop
* Memory requirement: 16GB RAM
* Storage requirement: 512GB
* Chatbot displayed price: 1999 GEL
* Product page displayed price: 2099 GEL

## Steps to Reproduce

1. Open the chatbot.
2. Ask the chatbot to recommend laptops.
3. Specify the required memory and storage.
4. Ask the chatbot to show a suitable product.
5. Open the product link provided by the chatbot.
6. Compare the price shown by the chatbot with the price shown on the product page.

## Expected Result

The chatbot should display the current product price shown on the product page.

If the price has changed, the chatbot should clearly inform the user that the displayed price may differ from the current product page price.

## Actual Result

The chatbot displayed a price of **1999 GEL**, while the linked product page displayed **2099 GEL**.

## Severity

**Medium**

## Priority

**High**

## Impact

* Users may receive incorrect pricing information.
* Users may make a purchase decision based on outdated information.
* The price mismatch can reduce user trust in the chatbot.

## Reproducibility

**Reproducible during manual testing**

## Recommendation

Synchronize chatbot product information with the current product data source.

If real-time synchronization is not possible, display a clear message informing users that the price may differ from the current product page.
