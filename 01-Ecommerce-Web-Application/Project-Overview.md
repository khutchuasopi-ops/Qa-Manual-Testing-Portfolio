# Project Overview

## Project

E-commerce Web Application

## Project Type

Web-based E-commerce Application

## Role

Junior Manual QA Tester

## Testing Approach

Manual functional testing of the web application, with a focus on the main user flows and e-commerce functionality.

## Testing Scope

The testing covered the following areas:

- User login
- Product search
- Product selection
- Product size selection
- Shopping cart
- Product quantity
- Cart price calculation
- Checkout flow
- Language/localization functionality

## QA Activities

During testing, I:

- Created and executed manual test cases.
- Defined high-level test scenarios.
- Created functional testing checklists.
- Tested important e-commerce user flows.
- Identified and documented defects.
- Reported bugs with reproduction steps, expected results, and actual results.
- Performed functional and UI checks.
- Verified product and shopping cart behavior.

## Test Documentation

The project includes:

- Test Cases
- Test Scenarios
- Functional Checklists
- Bug Reports
- Case Study

## Key Defects Identified

Examples of defects identified during testing include:

1. Website content remained in English after selecting another language.
2. Cart total price did not change when the product quantity was updated.
