# Project Overview — Legal Platform QA

## Project Overview

This project contains my manual QA testing work for a confidential legal technology platform.

The platform includes features for working with legal documents, templates, events, workflows, repositories, search, and AI-assisted functionality.

The application and company details are not included because of confidentiality.

---

## QA Role

**Junior Manual QA Tester**

I tested the application manually and documented test scenarios, test cases, execution results, exploratory findings, and bugs.

---

## QA Process

The testing process was:

1. Explore the application.
2. Identify the main features and user flows.
3. Create test scenarios.
4. Create detailed test cases.
5. Execute the tests.
6. Perform exploratory testing.
7. Report bugs.
8. Retest fixed issues.
9. Perform regression testing.
10. Document the final results.
