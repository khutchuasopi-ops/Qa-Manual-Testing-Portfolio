# BUG-003 — Invalid Email Accepted During Login

**Severity:** Medium
**Priority:** High
**Status:** Open
**Environment:** Web Application
**Module:** Login / Authentication

## Description

The login form accepts invalid email credentials and redirects the user to the home page.

## Steps to Reproduce

1. Open the e-commerce web application.
2. Navigate to the login page.
3. Enter an invalid email.
4. Enter the password used for the test.
5. Click the login button.
6. Check the result.

## Expected Result

The system should reject invalid login credentials and display an appropriate error message.

## Actual Result

The invalid email credentials are accepted and the user is redirected to the home page.
