# BUG-002 — Unable to Return to AI Chat After Requesting an Operator

## Summary

After the user requests connection to a human operator, the chatbot does not provide a clear way to return to the AI chatbot.

## Environment

* Application: Confidential AI-Powered E-commerce Chatbot
* Platform: Web
* Browser: Web browser
* Testing Type: Manual / Exploratory Testing

## Preconditions

* Chatbot is available.
* User can start a normal conversation with the chatbot.
* Operator connection functionality is available.

## Steps to Reproduce

1. Open the chatbot.
2. Start a normal conversation with the AI chatbot.
3. Select or request `Connect me to operator`.
4. Wait for the operator request confirmation.
5. Send a message such as `Never mind. Can you return to chatbot?`.
6. Observe the chatbot response.
7. Minimize the chatbot.
8. Reopen the chatbot.
9. Check whether the user can return to the AI chatbot.

## Expected Result

The chatbot should provide a clear way to return to the AI conversation if this functionality is supported.

If returning to AI is not supported after requesting an operator, the chatbot should clearly explain the current state and provide an appropriate next action, such as starting a new conversation.

## Actual Result

After requesting an operator, the chatbot remains in the operator-related state.

The user does not receive a clear option to return to the AI chatbot. After minimizing and reopening the chatbot, the same state remains active.

## Severity

**Medium**

## Priority

**High**

## Impact

* Users may become confused about the current chatbot state.
* Users may be unable to continue using the AI chatbot.
* The user experience is negatively affected.

## Reproducibility

**Reproducible during manual testing**

## Recommendation

Provide a clear action that allows the user to return to the AI chatbot when supported.

If the operator state cannot be cancelled, provide a clear explanation and an option to start a new AI conversation.

## Related Test Area

* Operator handoff
* Chat state management
* User flow
