# BUG-003 — Chatbot keeps operator state after being minimized and reopened

## Title

Chatbot remains in the previous operator state after minimizing and reopening

## Environment

- Platform: Alta AI Chatbot
- Browser: Web browser
- Testing type: Manual / Exploratory Testing

## Preconditions

- Chatbot is open.
- User has an active conversation.
- User has requested an operator.

## Steps to Reproduce

1. Open the chatbot.
2. Start a normal conversation.
3. Request an operator by sending:
   `Connect me to operator`
4. Wait until the chatbot confirms that the operator request was submitted.
5. Minimize the chatbot using the minimize button.
6. Reopen the chatbot without refreshing the page.
7. Check the current chatbot state.

## Actual Result

After reopening the chatbot, the previous operator state is still active.

The user is not offered an option to start or continue a normal AI chatbot
conversation.

The chatbot continues to treat the conversation as an active operator request.

Refreshing the page changes the behavior, but minimizing and reopening the
chat does not reset or change the state.

## Expected Result

After minimizing and reopening the chatbot, the system should restore the
conversation in a clear and usable state.

If the operator request is intentionally persistent, the chatbot should
clearly show the current status and provide an appropriate next action.

If the user is allowed to return to the AI chatbot, there should be a clear
option to do so.

The user should not need to refresh the entire page just to recover from an
unclear conversation state.

## Severity

Medium

## Priority

Medium

## Impact

The user may feel that the chatbot is stuck and may not know how to continue
the conversation.

This can negatively affect the chatbot user experience, especially when the
user changes their mind after requesting an operator.

## Evidence

The chatbot remained in the operator state after being minimized and
reopened.

Refreshing the page changed the state, while simply minimizing and reopening
the chatbot did not.
