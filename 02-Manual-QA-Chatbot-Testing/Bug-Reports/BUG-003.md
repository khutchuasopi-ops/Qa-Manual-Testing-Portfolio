# BUG-003 — Operator State Persists After Minimize and Reopen

## Summary

The chatbot remains in the previous operator-related state after being minimized and reopened.

## Environment

* Application: Confidential AI-Powered E-commerce Chatbot
* Platform: Web
* Browser: Web browser
* Testing Type: Manual / Exploratory Testing

## Preconditions

* Chatbot is available.
* User has an active chatbot conversation.
* An operator connection has been requested.

## Steps to Reproduce

1. Open the chatbot.
2. Start a normal conversation with the AI chatbot.
3. Request connection to a human operator.
4. Wait for the operator request confirmation.
5. Minimize the chatbot without refreshing the page.
6. Reopen the chatbot.
7. Observe the current chatbot state.

## Expected Result

After reopening, the chatbot should restore a clear and usable state.

If the operator request is intentionally persistent, the chatbot should clearly display the current status and the next available action.

If returning to the AI chatbot is supported, the user should have a clear option to return to the AI conversation.

## Actual Result

The chatbot remains in the previous operator-related state after minimize and reopen.

The user does not receive a clear option to continue with the normal AI chatbot conversation.

A page refresh changes the behavior, while minimize and reopen do not reset or clearly restore the chatbot state.

## Severity

**Medium**

## Priority

**Medium**

## Impact

* Users may feel stuck in an unclear chatbot state.
* Users may not understand how to continue the conversation.
* The user experience is negatively affected.
* State management behavior is inconsistent.

## Reproducibility

**Reproducible during manual testing**

## Recommendation

Review chatbot state management after minimize and reopen.

The chatbot should either:

* restore the previous state with clear status and actions, or
* provide a clear option to start or return to an AI conversation.

The behavior should be consistent without requiring a page refresh.

## Related Test Area

* Chat state management
* Operator handoff
* Session persistence
* User flow
