# Project Overview

## Product Type

Confidential Legal Technology Platform

## Application Description

The application is a legal document and workflow management platform designed to support organizations and their members in managing legal documents, templates, events, workflows, and AI-assisted legal operations.

## Main Functional Areas

### Dashboard

Provides an overview of activities and access to key platform functionality.

### Repository

Allows users to upload, manage, replace, and delete documents.

### Templates

Allows users to create and manage document templates and generate playbooks.

### Events

Allows users to create and manage legal-related events.

### Workflows

Provides workflow management and filtering functionality.

### AI Assistant

Provides AI-assisted interaction and responses related to legal content.

### Search

Allows users to search available documents and other platform data.

### Recycle Bin

Provides functionality for managing deleted items and restoring or permanently deleting them.
