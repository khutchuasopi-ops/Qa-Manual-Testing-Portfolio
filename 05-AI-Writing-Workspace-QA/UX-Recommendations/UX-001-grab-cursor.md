# UX-001 — Add a Grab Cursor for Draggable Template Elements

## Title
Add a grab cursor for draggable Template elements

## Current State
When hovering over a draggable text element in a Template, the cursor remains a regular arrow.

The element can be moved with the mouse, but there is no visual cursor indication that the element is draggable.

## Recommended Improvement
Consider adding a hand or grab cursor when hovering over draggable Template elements.

This would provide a clearer visual indication that the element can be moved.

## Expected Result
When the user hovers over a draggable Template element, the cursor should provide a clear visual indication that the element can be dragged.

## Priority
Low

## Area
Templates / UI / UX
