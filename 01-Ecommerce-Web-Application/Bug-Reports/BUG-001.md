# BUG-001 — Website Content Remains in English After Changing Language

## Bug Information

| Field       | Details         |
| ----------- | --------------- |
| Bug ID      | BUG-001         |
| Severity    | Medium          |
| Priority    | Medium          |
| Status      | Reported        |
| Environment | Web Application |
| Module      | Localization    |

---

## Description

After changing the website language, some application content remains displayed in English instead of the selected language.

This results in inconsistent language content across the application.

---

## Steps to Reproduce

1. Open the web application.
2. Change the website language to another supported language.
3. Navigate through the application.
4. Review the displayed text.

---

## Expected Result

All supported application content should be displayed consistently in the selected language.

---

## Actual Result

Some application content remains displayed in English after changing the language.

---

## Impact

Users may see mixed-language content, which can negatively affect the consistency and usability of the application.
