# BUG-004 — Chatbot compares a different product than requested

## Title

Chatbot replaces the requested Samsung S24 with Samsung S26 during comparison

## Environment

- Platform: Alta AI Chatbot
- Browser: Web browser
- Testing type: Manual / Exploratory Testing

## Preconditions

- Chatbot is available.
- User can ask the chatbot to compare products.

## Steps to Reproduce

1. Open the chatbot.
2. Send the following request:
   `Compare iPhone 16 and Samsung S24`
3. Review the chatbot response.
4. Check which Samsung model is used in the comparison.

## Actual Result

The chatbot compares **iPhone 16 with Samsung Galaxy S26** instead of the
requested **Samsung S24**.

The chatbot explains that S24 is not currently available in the catalog and
then continues the comparison using S26.

The replacement is made without first asking the user whether they want to
compare the S26 instead.

## Expected Result

The chatbot should compare the exact products requested by the user:

- iPhone 16
- Samsung S24

If Samsung S24 is not available in the catalog, the chatbot should clearly
inform the user and ask whether they would like to compare another available
Samsung model.

It should not silently replace the requested product.

## Severity

Medium

## Priority

High

## Impact

The user may believe they are receiving information about Samsung S24 when
the chatbot is actually describing Samsung S26.

This can lead to incorrect product comparisons and potentially influence the
user's purchasing decision.

## Evidence

User request:

`Compare iPhone 16 and Samsung S24`

Chatbot response:

The chatbot states that it is comparing iPhone 16 with Samsung Galaxy S26
instead of Samsung S24.
