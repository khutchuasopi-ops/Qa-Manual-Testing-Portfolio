# UX-002 — Add a Close Button to the Project Details Panel

## Title
Add a Close (X) button to the Project / Manuscript details panel

## Current State
The Project / Manuscript details panel can be closed by clicking outside the panel.

There is no visible Close (X) button inside the panel.

## Recommended Improvement
Consider adding a Close (X) button to the Project / Manuscript details panel.

This would provide users with a clear and familiar way to close the panel.

## Expected Result
The details panel should include a visible Close (X) button that allows users to close the panel directly.

Clicking outside the panel may remain available as an additional way to close it.

## Priority
Low

## Area
Project / Manuscript Details / UI / UX

## Environment
- Environment: Staging / Preview
- Testing type: Manual QA

## Status
Recommendation
