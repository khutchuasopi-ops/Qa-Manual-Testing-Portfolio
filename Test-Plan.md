# Test Plan

## 1. Objective

The objective of testing is to verify that the AI chatbot provides a reliable and user-friendly experience when customers search for products and ask product-related questions.

## 2. Scope

The following areas are included in testing:

- Product search
- Product information
- Product specifications
- Product prices
- Product recommendations
- Product comparison
- Conversation context
- Purchase flow
- Operator flow
- Chat state
- Error handling
- Invalid input
- Multilingual input
- Desktop testing
- Mobile testing

## 3. Out of Scope

The following areas are outside the scope of this manual testing project:

- Source code testing
- Database testing
- API testing
- Performance/load testing
- Security penetration testing
- Automated testing

## 4. Testing Types

The following testing approaches are used:

- Functional Testing
- Exploratory Testing
- Negative Testing
- Usability Testing
- Compatibility Testing
- Context Testing
- State Testing
- Data Consistency Testing

## 5. Test Environment

Testing is performed using:

- Notebook/Desktop
- Mobile device
- Supported web browsers

For each defect, the relevant device, operating system, browser and version should be recorded.

## 6. Entry Criteria

Testing can begin when:

- The chatbot is accessible
- The user can send messages
- The chatbot can return responses
- Product information is available
- Operator functionality is available for testing

## 7. Exit Criteria

Testing can be considered complete when:

- Planned scenarios have been executed
- Main chatbot flows have been explored
- Important defects have been documented
- Major risks have been identified
- Test results have been summarized

## 8. Main Risks

The main risks being investigated are:

- Incorrect product information
- Incorrect prices
- Loss of conversation context
- Incorrect recommendations
- Incorrect chatbot state
- Operator flow problems
- Incomplete handling of complex requests
- Inconsistent error handling
- Poor mobile usability
