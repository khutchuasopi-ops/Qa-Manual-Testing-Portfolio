# BUG-003 — Invalid Email Accepted During Login

## Bug Information

| Field       | Details                |
| ----------- | ---------------------- |
| Bug ID      | BUG-003                |
| Severity    | Medium                 |
| Priority    | High                   |
| Status      | Open                   |
| Environment | Web Application        |
| Module      | Login / Authentication |

---

## Description

The login form accepts an invalid email format instead of displaying a validation message.

This allows invalid input to be processed by the login flow.

---

## Steps to Reproduce

1. Open the login page.
2. Enter an invalid email format in the email field.
3. Enter a password.
4. Click the **Login** button.

---

## Expected Result

The application should validate the email format and display an appropriate validation message.

The user should not be allowed to continue with an invalid email format.

---

## Actual Result

The invalid email format is accepted and the login flow continues instead of displaying an email validation message.

---

## Impact

Users may receive unclear login behavior because invalid email input is not properly validated.

This can negatively affect usability and input validation.
